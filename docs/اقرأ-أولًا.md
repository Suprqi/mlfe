## ⛔ ما لا يعمل بعد — مطلوب من المطوّر

### ١. الوسيط (proxy) — **الأهم**
٢١ استدعاءً لواجهة الذكاء تمرّ من دالتين. بدونه **لا يعمل:**
- ✨ «ساعدني في صياغة التقرير»
- توليد الاختبارات والتحضير
- «من كلامك إلى ملفات»
- تحليل النتائج والخطط العلاجية

المفتاح **لا يوضع في الملف** — يبقى على الخادم. راجع `تسليم-المطوّر.md`.

### ٢. رفع مجلد `٣-القانوني`
**نموذج السفراء** يحيل إلى `malafi.sa/terms.html` و`privacy.html`،
و**صفحة الهبوط** تحيل إليها كذلك. بدون الرفع تُفتح صفحات ٤٠٤.

### ٣. نقاط النهاية الفارغة
```js
DRIVE_ENDPOINT = ''   // رفع الصور إلى درايف المعلّم
AW_ENDPOINT    = ''   // استقبال طلبات الجائزة
```
البنية جاهزة — ضع مسارك.

### ٤. تضمين الخطوط محليًّا
كلها تُحمَّل من Google الآن. بدون التضمين:
- التطبيق لا يعمل بخطوطه بلا إنترنت
- `html2canvas` يُخرج PDF بحروف عربية منفصلة

الخطوط النظامية الثلاثة (مجلة · بسيط · نسخ أدوبي) تحتاج ترخيص توزيع ويب — راجع الوثيقة.

### ٥. OAuth درايف
تصريح Google + مراجعة. مؤجَّل حتى ما بعد الإطلاق.

## قواعد لا تُخالَف

1. **`$()` = `getElementById` فقط** — لا محدّدات CSS
2. **الحالة في `S`** → `localStorage['malaffi_state_v1']`
3. **`V(m,f)`** للتجنيس حسب `S.gender` — لا تكتب نصًّا مذكّرًا مباشرة
4. **`renderQuickActions()`** تبني الشبكة ديناميكيًا — لا تعدّل HTML الثابت
5. **المسميات الرسمية:** مدير/مديرة المدرسة (لا قائد) · الموجه الطلابي (لا المرشد)
6. **الوثائق القانونية نسختان** — داخل التطبيق وعلى الموقع. أي تعديل يحتاج تحديثهما معًا
7. **شغّل `check.py` قبل كل نشر** — ١٩ فحصًا، منها توازن وسوم HTML
